# Class presentations

Slides for Howard Wang's class presentations, served with GitHub Pages.

- Site: https://howardwhsrun.github.io/presentation/
- Each presentation is one self-contained HTML file in its own folder, for example `ece523-paper3/index.html`.

## Adding a presentation

1. Create a folder with a short name, such as `ece587-v1/`.
2. Put the deck in it as `index.html`.
3. Add a list entry for it in the root `index.html`.

## Deck controls

Arrow keys or click to move, `N` for speaker notes, `F` for fullscreen.

Figures from published papers remain the property of their publishers and are shown here for class discussion.
