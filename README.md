# Class presentations

Slides for Howard Wang's class presentations, served with GitHub Pages.

- Site: https://howardwhsrun.github.io/presentation/
- Each presentation has its own folder with two self-contained HTML files:
  - `index.html` is the viewer version: slides only, no script.
  - `presenter.html` is the presenter version: slides plus the speaker script, a slide counter and a timer.

## Adding a presentation

1. Create a folder with a short name, such as `ece587-v1/`.
2. Put the viewer deck in it as `index.html` and the presenter deck as `presenter.html`.
3. Add a list entry for it in the root `index.html`.

## Deck controls

Arrow keys or click to move, `F` for fullscreen.

In the presenter version, `N` hides or shows the script. "Open audience window" opens the viewer version in a second window that follows the presenter window slide by slide, so the projector can show the slides while the laptop shows the script.
